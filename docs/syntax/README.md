# Syntax Workspace

This directory stores syntax design artifacts only. Design review standards and
Agent expectations live in `.trellis/spec/`.

| Directory | Meaning |
| --- | --- |
| [current/](./current/) | Current decisions that implementation work should target. |
| [design/](./design/) | Active design notes and exploratory drafts. Use as context, not as automatic requirements. |
| [archive/](./archive/) | Historical syntax references kept for migration and regression evidence. |
